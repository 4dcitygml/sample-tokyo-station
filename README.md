東京駅を含む千代田区データセットの建物データ（CityGML）を、プルリクエスト（PR）で
協働管理しています。**このリポジトリは必要時に初期状態へ戻す練習用サンドボックスです** —
本番の都市データに参加する前に、編集ツールと PR の流れを安心して学べます。

- **はじめかた（練習）**: `install/start-mac.command`（macOS）または
  `install/start-windows.bat`（Windows）を実行してください。共有編集ツールが自動で
  ダウンロードされ、この都市に接続します（都市選択は不要です）。
  クローンから最初の提案までの詳しい手順は [はじめかた](docs/ja/getting-started.md) を参照。
- **データ出典・ライセンス**: `4dcitygml.json` の `attribution` / `license` を参照
  （3D都市モデル Project PLATEAU 千代田区（2023年度）／国土交通省 — CC BY 4.0）。
- **見た目の設定**: `theme.json`（宣言的トークンのみ。変更は PR レビューを経由）。
- **都市ロゴ（任意）**: `4dcitygml.json` の `logo` にリポジトリ内のラスタ画像
  （png / jpg / jpeg / webp、1 MiB 以下）を指定すると各ツールの左上に表示されます。
  SVG は受け付けません — 直接開くとスクリプトが実行され得るため、テーマと共通の
  「構造的に XSS を作らない」設計が壊れます。

## データをビューアでそのまま見る

編集に参加せず CityGML を眺めるだけなら、KIT（カールスルーエ工科大学）の
無償 Windows ビューア **[KITModelViewer](https://www.iai.kit.edu/english/4561.php)**
（旧 FZKViewer の後継）で、このリポジトリの GML をそのまま開けます。
CityGML 2.0 世代の旧 [FZKViewer](https://www.iai.kit.edu/english/1648.php)
（6.3 で開発終了）でも表示できます。

- テクスチャ付きで見るには、GML 単体ではなく**リポジトリ一式**
  （Code → Download ZIP、または clone）を取得し、フォルダ構成を保ったまま
  `13101_chiyoda-ku_pref_2023_citygml_1_op/udx/bldg/` の GML を開いてください
  （テクスチャは隣の `53394611_bldg_6697_appearance/` から相対参照されます）。
- 属性の編集・提案まで行う場合は、上記「はじめかた（練習）」の共有編集ツールを
  使ってください。

## 練習環境について

現在は**日次リセットと自動マージを無効化**しています。本番データに影響を与えずに、
管理者の確認を伴うツールとPRの流れを練習するためのサンドボックスです。

- **手動リセット**: 管理者が必要と判断し、確認語`RESET`を入力した場合だけ、`main`を
  `baseline`へ戻します。リセット時にはオープン中のPRへ案内します。
- **手動マージ**: すべてのPRを管理者が確認してからマージします。自動マージ用コードは
  将来の検討に備えて残していますが、専用変数が未設定のため起動しません。
- **リセット後は fork を同期**: このリポジトリを fork している場合、次の練習の前に
  GitHub 上で **Sync fork** → **Update branch** を押してください。同期しないと、
  リセットで消えた前日の編集が次の PR の差分に混入し、コミット範囲検査で弾かれます。
  - **公式編集ツールを使う場合**: ツール起動時に自動で同期されるため、
    手動での Sync fork は不要です。

## 記録についてのお知らせ

練習PR、レビュー、CIコメントは公開リポジトリ上の通常のGitHub履歴として残ります。
現在、これらを別の練習ログ用リポジトリへ収集・保存する処理は有効化していません。
公開してよい情報だけをPRとコメントへ記載してください。
