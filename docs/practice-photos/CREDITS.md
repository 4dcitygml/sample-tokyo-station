# Practice photos

Photos of building facades in this practice area, for practising the texture editor:
`01` a frontal view (use only part of a photo), `02` and `03` the same large building from
different angles (combine several photos on one building), `04` a nearby building.

Every photo is CC0 or public domain (source: Wikimedia Commons). Each was resized by the Wikimedia
thumbnailer to 1920 px wide, some were cropped to leave out the street level (people, vehicles),
and all metadata (EXIF, XMP, ICC, comments) was removed. Author names are given in ASCII as listed
on the source page. In this practice repository these photos may be used in texture pull requests
([data contribution policy](../data-contribution-policy.md), section 2 item 5). They are not
covered by the Apache License 2.0 of this repository's documentation (see LICENSE).
